# 主张与范围

本文把句子分成三类。**计划中的贡献**是打算做的事，现在还没有证据。**核对过的事实**只在别的文档里、并且能指回来源。**解释**是我们为什么这样设计，不是测量结果。

## 1. 研究问题

在模型、工具、任务和每轮注入预算相同的条件下，知识库的结构会不会改变长周期代理工作的有效性和开销？第一块任务是程序分析中的漏洞发现：写入代理把观察放进知识库，交接代理看不到源码、也看不到原对话，只凭知识库回答“有没有缺陷、哪一类、在何处、证据是哪条记录”。

这是 [../03-benchmark-design.md](../03-benchmark-design.md) 第 1 节的同一问题，这里写成论文可用的表述。它问的是记忆结构，不是哪一个渗透系统在比赛里得分更高。

## 2. 计划中的贡献

下面四条都是**计划**，不是已经成立的主张。

1. 一个把结构从编排、模型和教令里拆出来的基准协议：三臂共用工具名和注入预算，变的是记忆怎么存、怎么被读回。
2. 一组同时覆盖有效性与效率的指标定义：判断、类别、位置、证据是否能在源码和知识库里对上，以及 token、时延、取回的上下文大小。定义见设计文档，没有数值。
3. 一份针对 Juliet 命名和注释泄漏的脱敏协议，以及“交接失败时先改提示和预算”的默认顺序。见 [juliet-sanitization.md](juliet-sanitization.md) 与 [design-decisions.md](design-decisions.md)。
4. 一篇相关工作笔记，把黑板图、分层记忆、实体图 RAG、向量分块和漏洞检测数据集放在同一张地图里，并写明哪些还不能当作本基准的结果。见 [literature.md](literature.md)。

文章若要声称“某结构更有效或更省”，必须在这些计划执行并记入 `docs/status.md` 之后。在那之前，论文草稿的贡献节应使用“we will”而不是“we show”。

## 3. 明确不声称的事

- 不声称事实—意图图、向量库或扁平笔记谁更好。没有对照实验。
- 不把 sapper-v2 或 Cairn 的比赛名次、flag 数、token 数、费用当作结构实验的结果。这些是作者自述，而且来源之间并不一致：nvwabase / sapper-v2 的 README 与公众号长文对 token 的写法不同（见 [../01-nvwabase.md](../01-nvwabase.md)）；Cairn README 写第二届腾讯云黑客松排名第 3，复盘文写在动态计分下唯一 AK 仍是第 4，另一篇答辩文写最终成绩全国第 3。详见 [literature.md](literature.md)。本仓库没有核验榜单。
- 不声称 Cairn“零 RAG”或 sapper“省 token”已经证明图优于向量检索。两套系统同时改变了运行时、模型、人工介入和任务。Cairn 复盘明确写比赛系统反对用传统 RAG，并在第四天晚上做了人工复盘。那是架构选择的自述，不是消融。
- 不声称 nvwabase 当前 `fgc` 具有类型化事实。该实现在 sapper-v2。见 [../01-nvwabase.md](../01-nvwabase.md)。
- 不把 PrimeVul、Magma 或 GraphRAG 论文里的分数当作本仓库的发现。那些数字只说明原文在它们自己的任务上报告了什么。
- 不提供利用步骤，也不把“能否打穿目标”当作知识库质量的指标。

## 4. 效度威胁（论文讨论节可直接用）

与 [../03-benchmark-design.md](../03-benchmark-design.md) 第 7 节相同，这里收成文章语言。

- **结构与读取方式绑在一起。** 图臂的搜索是 token 重叠，向量臂是嵌入，笔记臂是子串。v1 的结论只能写成“结构及其自带读取方式”，除非以后单独立臂拆开检索器。
- **标签泄漏。** Juliet 的目录、文件名、函数名和文件头注释携带 CWE 与 good/bad。未按 [juliet-sanitization.md](juliet-sanitization.md) 处理并抽查之前，正结果不能解释成模型读懂了代码。
- **合成数据与短文件。** Juliet 用户指南自己写明：用例里的缺陷频率不像自然代码，自然代码上的真假阳性率可以差很远。短文件还可能让扁平笔记把全文放进预算。
- **地板效应。** 交接代理看不到源码。三臂一起失败时，默认先改提示和 `B_inject`，而不是立刻把源码交给交接代理。见设计决定。
- **模型记忆。** 选定模型之后仍无法从公开材料断定它是否在训练中见过 Juliet。这是残余威胁，要在论文里写明，而不是假装脱敏就消除了参数记忆。
- **单模型、单提示词。** 交互效应未知。换模型或改提示是新实验。
- **并发未测。** 文件锁防止写坏，不防止两条事实互相矛盾。
